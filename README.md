# PPVT 그림어휘력 검사

취학 전 아동을 위한 10문항 그림어휘력 검사 프로토타입입니다.

## 구성
- 동물 5문항, 일상용품 5문항
- 문항마다 정답 1개와 오답 3개
- 문항별 반응 시간 기록
- 총점수, 범주별 점수, 평균 반응 시간 대시보드
- 브라우저 로컬 저장소에 검사 기록 저장
- CSV 내보내기

## 실행
정적 파일이므로 index.html을 브라우저에서 열면 됩니다. 별도 서버나 빌드 도구가 필요하지 않습니다.
